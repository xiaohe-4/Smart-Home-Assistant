# 产品主流程

## 业务闭环

```text
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 1 看懂为何贵  │ →  │ 2 查清哪笔浪费│ →  │ 3 今晚关哪一档│
│ 总览回放     │    │ 异常解释器   │    │ 策略 + 管家  │
└──────────────┘    └──────────────┘    └──────────────┘
```

## 数据与模型流

```text
电力 / 温湿度 / 占用 / 天气
        │
        ▼
  重采样对齐到 5 分钟合同（缺一路 → 降级）
        │
        ▼
  ┌─────┴─────┬────────────┐
  ▼           ▼            ▼
XGBoost预测  IF打分+规则   分路汇总/可选负荷识别
  │           │            │
  └─────┬─────┴────────────┘
        ▼
  多目标策略引擎 → 管家模拟执行 → 生活系统反馈
        │
        ▼
  指标落盘 models/metrics.json（实验舱可核对）
```
