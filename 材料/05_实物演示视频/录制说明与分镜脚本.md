# 实物演示视频 · 录制说明与分镜

比赛提交项：**MP4，≤ 3 分钟，≤ 200 MB，画面清晰、声音清楚。**

本文件是分镜脚本。视频必须由选手在本机对**正在运行的系统**实操录制，不能用 PPT 配音代替。

## 录制前

1. 启动后端 `127.0.0.1:8000` 与前端 `127.0.0.1:5174`
2. 用 Chrome / Edge 打开：http://127.0.0.1:5174/
3. 不要用会变成 IPv6 的 localhost
4. 关闭免打扰，管家音量适中
5. 建议 1920×1080 窗口，全屏录制
6. 录完用系统自带剪辑压到 3 分钟以内，导出 MP4，放到本目录并命名：

`05_实物演示_智家能.mp4`

## 分镜（合计约 170 秒）

| 秒 | 画面 | 口播要点 |
| --- | --- | --- |
| 0–8 | 海报或总览全貌，出标题「智家能」 | 智家能，家庭能源智能决策。看懂用电，发现浪费，一句话去办。 |
| 8–28 | 总览：今日约 18.73 kWh、评分、电费、碳排；拖回放到 03:00 再回到 20:30 | 成都四口之家，演示日 8 月 19 日。凌晨有浪费，晚上是高峰。 |
| 28–45 | 能耗分析：空调约 41%、热水器约 22%、冰箱约 12%；高峰橙色带 | 占比来自分路电表，不是把总表盲拆。 |
| 45–65 | 异常页：点 03:17 热水器，展示规则归因；可快速闪过 F1 0.35 | 异常分加规则。F1 是 0.35，我们主动展示，不虚报准确率。 |
| 65–85 | 预测页：24 小时曲线与绿色 RMSE 带宽；可切模型实验舱 R² 0.9525 | 预测是 XGBoost，R² 0.9525，带宽就是误差。 |
| 85–110 | 策略页：已有模拟结果，指用电/电费/碳排前后对比和削峰曲线 | 空调 24 度调到 26 度，今晚就能少花高峰的钱。 |
| 110–140 | 管家宝强：说「汇报一下」，再「执行今晚节能方案」；冰箱拒绝可一句带过 | 建议能被执行。管家去拧开关，冰箱不会关。 |
| 140–160 | 生活系统：电价时钟、电网邀约或今晚任务一点应邀 | 高峰还剩多少分钟，邀约一点就能办。 |
| 160–170 | 数据来源四路对齐 100%，切回总览收束 | 多模态是四路时序。产品已经跑起来了。 |

## 禁止

- 超过 3 分钟
- 长时间念 PPT
- 只拍静态页、不点不拖
- 编造全市平均电量或把负荷识别说成总表 NILM
- 画面里出现指导教师、专利、合同、论文

录制完成后删除本说明是否保留：建议 **分镜脚本与 MP4 一起放在材料目录**，上传比赛系统时只传 MP4。
