# PPT 大纲

1. 问题：家庭用电看不懂、浪费看不见、建议不可执行
2. 定义：多模态家庭能源智能决策系统（四路时序，不是图像）
3. 闭环：感知 → 分析 → 预测 → 诊断 → 决策 → 管家执行 → 生活反馈
4. 架构：React + FastAPI + SQLite + XGBoost / IF / RF + 规则引擎
5. 数据：30 天 / 5 分钟 / 8 类家电 / 环境与行为 / 演示日对齐 100%
6. 预测实验：MAE 95.91 W · RMSE 203.30 W · MAPE 17.52% · R² 0.9525 · 准确率 82.48%（100-MAPE）
7. 异常实验：P 0.26 / R 0.54 / F1 0.35 · 标注 13 / 检出 27（主动展示）
8. 负荷识别：RF Accuracy 0.9513，有标签窗口，不是总表 NILM
9. 策略模拟：今日 18.73 kWh，空调升温 + 错峰，优化前/后曲线
10. Demo 十一幕：总览 → 能耗 → 异常 → 预测 → 策略 → 模拟 → 管家 → 生活 → 今晚闭环 → 数据合同 → 模型实验
11. 移植性：仿真灌表；换适配器与电价；缺模态降级
12. 下一步：真实电表接入、可选 LLM 解释层（仍不算指标）
