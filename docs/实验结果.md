# 实验结果

本页数值全部来自 `scripts/train_models.py` 真实运行结果，文件备份见 `models/metrics.json` 与 `data/processed/experiment_results.json`。重新训练后以最新文件为准。

训练时间：2026-08-19

## 实验 1：能耗预测

- 模型：XGBoostRegressor
- 样本：696 个小时级样本（30 天家庭负荷）
- 验证：TimeSeriesSplit（3 折）后汇总

| 指标 | 结果 |
| --- | --- |
| MAE | 95.91 W |
| RMSE | 203.30 W |
| MAPE | 17.52% |
| R² | 0.9525 |
| 切分 | TimeSeriesSplit 三折 |
| 对照 | 昨天同时段、近 7 日同时段平均（见 metrics.json 的 baseline_*） |

## 实验 2：异常检测

- 模型：Isolation Forest + 规则标注
- 对照：脚本植入的 13 个异常时间点

| 指标 | 结果 |
| --- | --- |
| Precision | 0.2593 |
| Recall | 0.5385 |
| F1 | 0.3500 |
| 检出条数 | 27 |

Demo 关键事件「2026-08-19 03:15 热水器异常启动」可被规则与模型联合检出。

## 实验 3：家电负荷识别

- 模型：RandomForestClassifier
- Accuracy：0.9513
- Macro-F1：0.9515
- 任务定义：有设备分路标签时，用 1 小时功率窗识别设备类型
- **不是**无标签总表 NILM；演示页的设备占比来自分路电表汇总

## 实验 4：节能策略模拟

- 演示日用电：18.73 kWh
- 主要负荷：空调 41.3%，热水器 22.3%，冰箱 11.8%
- Top 1 策略：空调温度从 24℃ 调整到 26℃
- 调用 `POST /api/strategies/simulate` 可得到优化前/后对比，结果随当前数据实时计算
