# 答辩稿（3 分钟）

各位老师好。我们是智家能：给家庭今晚一张「该关什么」的执行单，并能模拟执行后的电费变化。

电表只告诉你这个月多少度。我们回答三件事：为什么贵、哪笔是浪费、今晚关哪一档。

这是成都四口之家的夏季演示，连续 30 天，时刻 2026-08-19 20:30。演示户是仿真，为了稳定打出 03:17；另有验证户证明能灌真表/公开集。

**幕 1 总览。** 回放今日到 20:30。今日约 18.73 kWh，空调约 41%。贵，主要贵在空调。

**幕 2 异常解释器。** 03:17 热水器启动。规则：时段不合理、占用低、功率偏离。模型 F1 只有 0.35，所以结论以规则为准，Isolation Forest 只打分。我们不做成自动断电器。

**幕 3 策略和管家。** 执行空调 24→26℃，屏幕上出现电量、电费、削峰前后对比。假设按本户今日空调电量估算。管家点头执行；再说关冰箱，会被拒绝。现场是模拟控制，不接真实插座。

收束三句：分路汇总不是 NILM；演示户是仿真、验证户做迁移；模型可复现，不用大模型报准确率。

评委若问数据，切到验证户和 `/sources` 对照表。预测在验证户上变差也写在表上，我们不把仿真 R² 当成真实家庭精度。
