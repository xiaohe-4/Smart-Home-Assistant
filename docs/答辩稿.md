# 答辩稿

各位老师好，我们汇报的项目是「智家能——基于多模态家庭数据分析的 AI 能源管理与节能决策系统」。

智家能面向普通家庭。它融合电力、室内环境、占用行为和天气四路时序，回答三件事：为什么耗电、哪里在浪费、今晚具体怎么做。数值由 XGBoost、Isolation Forest、RandomForest 和规则引擎计算，大模型只做解释，不算指标。

请看 Demo。这是成都四口之家的夏季场景，系统已连续运行 30 天，演示时刻是 2026-08-19 20:30。

第一幕总览：今日用电约 18.73 kWh。回放到 03:00 能看见凌晨浪费，再回到 20:30 看晚高峰。四路数据对齐 100%。

第二幕能耗：空调约 41%，热水器约 22%，冰箱约 12%。这是分路电表汇总，不是总表盲拆。

第三幕异常：03:17 热水器 unusual_time。Isolation Forest 给分，规则说明时段不合理。实验对照 13 个植入点，检出 27 条，Precision 0.26、Recall 0.54、F1 0.35。我们主动展示，不把检出条数当准确率。

第四幕预测：XGBoost，R² 0.9525，MAPE 17.52%，准确率按 100-MAPE 计为 82.48%。绿色带宽就是 RMSE。特征重要性里有占用和室内温度，没有室外天气。

第五、六幕策略：空调 24℃ 调到 26℃，热水器避开高峰，系统按舒适滑杆模拟削峰曲线。

第七幕管家宝强：能汇报、能点头确认、能拧设定温度，冰箱拒绝关闭。控制是模拟执行，不改历史曲线。

第八、九幕生活系统：电价时钟、今晚任务、电网削峰邀约、谷电预约。一点应邀，宝强去执行。

第十幕数据来源：演示是仿真灌进标准表。移植时换采集适配器和本地电价，再按户重训。缺行为模态时，占用特征会降级。

第十一幕模型实验舱：四组实验的落盘数字和诚实说明集中在一页。负荷识别 Accuracy 0.9513，请记住那是有标签窗口分类。

答辩收束：空调占四成所以耗电；03:17 热水器和晚高峰是浪费；管家可拧到 26℃ 并掐夜间加热；多模态是四路时序不是图像；模型可复现，不拿 LLM 算指标。
