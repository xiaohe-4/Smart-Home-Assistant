# 产品介绍

智家能：给家庭今晚一张「该关什么」的执行单，并能模拟执行后的电费变化。

电表只告诉你这个月多少度。系统回答三件事：为什么贵、哪笔是浪费、今晚关哪一档。

## 三个功能

1. 回放找贵因：总览拉到 20:30，看今日电量、电费和第一耗电设备。
2. 规则解释异常：03:17 热水器。主规则、辅模型打分。F1=0.35 主动说。
3. 模拟执行并对比电费：空调 24→26℃，管家点头执行，拒绝关冰箱。现场不接真实插座。

## 技术

XGBoost 预测（MAE/RMSE/MAPE/R²，对照昨天同时段与近 7 日同时段平均）；规则 + Isolation Forest 解释异常；策略按本户今日电量估算。不接大模型报分。

## 数据

- 演示户：成都仿真四口，完整四路，现场主演示。
- 验证户：14 天、3 路插座，无占用/天气，预测走降级特征。可替换为真实导出或公开集切片。

## 边界

演示含仿真。有分路标签的 1 小时窗分类 Accuracy 0.95，设备占比来自分路求和，不是总表 NILM。无分路不做家电识别。不控制真实电器。

## 现场 3 幕（150 秒）

1. `/` 回放今日  
2. `/anomaly` 03:17 规则解释  
3. `/strategy` → `/butler` 执行并拒绝关冰箱
